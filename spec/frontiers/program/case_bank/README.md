# Case bank — testing the central hypothesis for a "fourth route"

> **Thesis on trial (RC):** *valid consent requires a preserved exit right.*
> The paper [`paper/three_questions.md`](../../../../paper/three_questions.md) argues
> RC has **no fourth route**: on every case it collapses to **Rothbard** (permit —
> bare consent), **Sen** (deny — adaptive preference), or **Pettit** (deny —
> domination), and is never distinct-and-right on its own. This bank stress-tests
> that claim across breadth: **61 real cases**, each scored against all four theories
> with the same rubric, hunting for even one genuine exception.

## Rubric

For each case: Rothbard | Sen | Pettit | **FDK-RC** (is a real exit preserved?) |
**collapses-to** (which existing theory FDK's verdict reduces to) | **fourth route?**
(does FDK differ from *all three* AND defensibly, without importing welfare / autonomy
/ domination?). The decisive split: **foreclosed exit** ⇒ RC denies, but only via an
imported person-premise (→ Rothbard's inalienability or Pettit's domination);
**retained-but-unwanted exit** (the contented cases, node K) ⇒ RC must permit
(= Rothbard) unless it judges the preference deformed (= Sen).

## The combined tally

| Outcome | Count (of 61) |
|---|---|
| **Genuine fourth route** (FDK distinct-and-right, no import) | **0** |
| Collapses to **Pettit** (non-domination; foreclosed exit) | majority of foreclosure cases (~20+) |
| Collapses to **Rothbard** (retained exit ⇒ RC permits = bare consent) | ~10 |
| Collapses to **Sen** (deny only by judging the deformed wanting) | the node-K residue (~8) |
| Control cases (all four agree ALLOW: at-will job, caffeine, terminable contract) | 3 |

**Zero fourth routes in 61 cases.** The breadth does not rescue RC; it confirms the
analytic result. The pattern is exactly as predicted:

- **Foreclosed-exit cases** (irrevocable servitude, company scrip, confiscated
  passports, non-portable data, bonded labor) → RC denies, but the *ground* of the
  denial is non-domination; RC supplies the *operationalization* (a measurable
  proxy: is exit secured?), not the justification. RC ⊆ Pettit.
- **Retained-but-unwanted cases** (the contented slave with manumission available, the
  willing addict, the cradle cult member) → RC's letter forces ALLOW (= Rothbard);
  any denial imports Sen's interest-judgment. Node K, every time.

## The single closest candidate — and why it still fails

The most concrete place RC could have escaped is **data portability** (case 02-#1):
exit is machine-checkable (can you export your data and leave?), with no welfare or
"wanting" judgment required. Even there, the honest finding is that RC **implements**
non-domination rather than adding to it: portability is the *proxy* for secured exit,
but *why* foreclosed exit is illegitimate is still Pettit's answer, not a new one. RC
contributes engineering precision to an existing normative claim — which is exactly the
paper's overall verdict in miniature.

## What this bank establishes

Not that RC gives *wrong* verdicts — it usually gives the intuitively right one. It
establishes that RC gives the right verdict **for a reason that already belongs to
Rothbard, Sen, or Pettit**, and never for a reason of its own. Scaling from 61 to 600
cases would be mechanical and would not change this; a fourth route, if it exists, will
be found by *argument* (closing the Q2 derivation without an imported premise), not by
*enumeration*. On present evidence there is none.
