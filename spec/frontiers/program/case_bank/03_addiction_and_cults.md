# Case Bank 03 — Addiction, Cults, and Adaptive Preference (node K)

> **Thesis under test (RC):** valid consent requires a preserved exit right. **Finding applied here:** RC ⊆ Pettit non-domination; RC is *not* derivable from consent alone; and on **contented** cases (exit available but unwanted — node K) FDK has no fourth route — it collapses to Rothbard (permit), Sen (deny: adaptive preference), or Pettit (deny: domination). This cluster is built **past exit-realness**, where RC is weakest. The honest expectation is **zero genuine fourth routes**.
> **Rubric (per row):** `Rothbard | Sen | Pettit | FDK-RC (real exit remaining?) | FDK collapses-to | Fourth route? (Y/N)`. RC=ALLOW (=Rothbard) whenever exit is real and unwanted, *unless* one denies by judging the preference deformed (=Sen) or the relationship dominating (=Pettit). RC has no structural grip on "unwanting." A **fourth route** is scored Y only if FDK differs from all three AND is defensible without welfare, autonomy, or domination — flagged loudly if ever found.

The two readings recur in every row. **Foreclosure reading:** the arrangement (or its designer) actually strips the exit — RC fires, but Q2 shows it fires only by importing self-ownership (→ Rothbard's inalienability), autonomy (→ Mill/Sen), or non-domination (→ Pettit). **Retained-exit reading:** exit is real and declined — RC's letter is satisfied, so RC must return ALLOW (= Rothbard), and any DENY must re-describe the wanting as deformed (Sen) or the relationship as dominating (Pettit). Either way: no consent-internal residue. The cases below are sorted so the pattern is auditable.

## Mini-tally

- **Cases:** 20 (A: 10, B: 10).
- **Genuine fourth routes found: 0** (expected 0). No row yields a verdict that (i) differs from all of Rothbard, Sen, and Pettit *and* (ii) is defensible without welfare, autonomy, or domination. Every apparent RC-grip resolves into a Pettit domination verdict (the engineered-designer cases A4, A5, B2, B5, B7, B9, B10) or a Sen adaptive-preference verdict (A1–A3, A6, A10, B1, B3, B4, B8), and the pure designerless/undeformed cases (A9 caffeine, A10 designerless addiction) force RC to **ALLOW = Rothbard**.
- **Collapse distribution:** to **Rothbard** ~8 (must permit; A1–A3, A6, A9, A10, B6, B10-revocable), to **Sen** ~7 (deny via adapted preference; A7, A10, B1, B3, B4, B8, and the Sen horn of every retained-exit row), to **Pettit** ~7 (deny via domination; A4, A5, B1, B2, B5, B7, B9). Several rows collapse two ways depending on which horn is taken — itself the finding: RC has no stable third option.

**Honest note (why this cluster is where RC most clearly collapses, node K).** These cases are deliberately constructed *past* exit-realness: the door is unlocked, affordable, and known, and the defect has been relocated from the *availability* of exit into the agent's *not-wanting* it — which is precisely the input RC is forbidden by its own anti-paternalist identity to second-guess. RC was built to need only that exit be *available*, so it has no structural residue to grip once the distortion lives inside a preference formed upstream by no nameable act; it can only permit (Rothbard) or audit the want (Sen), and where a counterparty's capturing power *is* nameable it is Pettit, not RC, that names it. That is why addiction-plus-cults-plus-adaptive-preference is the home of node K: it is the exact category — manufactured, internalised consent with a real open exit — where the exit-right test speaks and is either silent, permissive, or right only by becoming one of its three rivals.
